Petunjuk Konfigurasi Supabase:

  1. Buka dashboard Supabase di supabase.com dan buat proyek baru.
  2. Masuk ke menu SQL Editor, buka file supabase_schema.sql dari proyek ini, lalu klik Run.
  3. Buka Project Settings -> API, salin Project URL dan service_role (atau anon key).
  4. Buka file backend/.env dan atur nilai: 
    SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
SUPABASE_KEY=eyJh......
  5. Jalankan ulang server backend (npm start). Backend akan otomatis terhubung ke database Supabase Cloud!
